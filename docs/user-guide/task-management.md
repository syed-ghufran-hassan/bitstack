# Task Management User Guide

## Getting Started

### Creating Your First Task

1. **Connect Your Wallet**
   - Click "Connect Wallet" in the header
   - Select your preferred Stacks wallet
   - Approve the connection

2. **Navigate to Create Task**
   - Click "Create Task" in the navigation
   - Fill out the task form with details

3. **Set Task Parameters**
   - **Title**: Clear, descriptive task name
   - **Description**: Detailed requirements
   - **Amount**: Payment in STX
   - **Deadline**: Block height deadline
   - **Priority**: Low, Normal, or High
   - **Category**: Design, Development, Marketing, Writing

### Managing Tasks

#### As a Task Creator

- **Monitor Progress**: Track task status and milestones
- **Communicate**: Use comments to clarify requirements
- **Review Work**: Evaluate submissions thoroughly
- **Rate Workers**: Provide feedback after completion

#### As a Worker

- **Browse Tasks**: Filter by category, priority, and amount
- **Accept Tasks**: Only accept tasks you can complete
- **Submit Work**: Provide clear proof of completion
- **Build Reputation**: Complete tasks on time and well

### Task Lifecycle

1. **Open**: Task is available for workers to accept
2. **In Progress**: Worker has accepted and is working
3. **Submitted**: Worker has submitted their work
4. **Completed**: Creator has approved and payment released
5. **Disputed**: Either party has raised a dispute

### Best Practices

- Set realistic deadlines
- Provide clear requirements
- Communicate regularly
- Use milestones for large tasks
- Rate fairly and honestly
