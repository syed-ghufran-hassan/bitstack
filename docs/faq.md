# Frequently Asked Questions

## General Questions

### What is BitStack?
BitStack is a decentralized marketplace for microgigs built on the Stacks blockchain. It allows users to post tasks with STX rewards and enables workers to complete them trustlessly.

### How does BitStack work?
Tasks are managed by smart contracts on Stacks. When you create a task, your STX is locked in escrow. When work is approved, payment is automatically released to the worker.

### Is BitStack secure?
Yes, BitStack leverages Bitcoin's security through Stacks' Proof of Transfer mechanism. All funds are held in audited smart contracts.

## Task Management

### How do I create a task?
1. Connect your Stacks wallet
2. Click "Create Task"
3. Fill in task details and amount
4. Submit and confirm the transaction

### What happens if work isn't satisfactory?
You can request revisions or initiate a dispute. The dispute resolution system helps resolve conflicts fairly.

### Can I cancel a task?
Yes, you can cancel open tasks before they're accepted. Your STX will be automatically refunded.

## Payments

### What currencies are supported?
Currently, BitStack supports STX payments. sBTC support is planned for future releases.

### When are payments released?
Payments are released automatically when you approve completed work. This happens instantly on-chain.

### Are there any fees?
BitStack charges no platform fees. You only pay Stacks network transaction fees.

## Technical Issues

### My wallet won't connect
- Ensure you have a compatible Stacks wallet installed
- Check you're on the correct network (testnet/mainnet)
- Try refreshing the page

### Transaction failed
- Check you have sufficient STX for gas fees
- Verify task parameters are valid
- Ensure the task hasn't expired
