# Getting Started with BitTask

## Quick Start

1. **Connect Your Wallet**
   - Click "Connect Wallet" in the top right
   - Choose your Stacks wallet (Hiro, Xverse, etc.)
   - Approve the connection

2. **Browse Tasks**
   - Visit the "Browse Tasks" page
   - Filter by status, category, or priority
   - Click on any task to view details

3. **Create a Task**
   - Go to "Create Task" page
   - Fill in title, description, amount, and deadline
   - Select priority and category
   - Submit and confirm the transaction

4. **Accept and Complete Tasks**
   - Find an open task you can complete
   - Click "Accept" to become the assigned worker
   - Complete the work and submit proof
   - Wait for creator approval to receive payment

## Common Use Cases

### For Task Creators
- Post design work (logos, graphics, UI/UX)
- Request development tasks (bug fixes, features)
- Get marketing content (articles, social media)
- Commission writing (documentation, blogs)

### For Workers
- Browse available tasks by category
- Accept tasks matching your skills
- Submit work and get paid in STX
- Build reputation through ratings

## Troubleshooting

### Wallet Connection Issues
- Ensure you have a Stacks wallet installed
- Check that you're on the correct network (testnet/mainnet)
- Try refreshing the page and reconnecting

### Transaction Failures
- Ensure you have enough STX for gas fees
- Check that task parameters are valid
- Verify the task hasn't expired or been taken

### Payment Issues
- Payments are automatic upon work approval
- Check transaction status in your wallet
- Contact support if payments are delayed
