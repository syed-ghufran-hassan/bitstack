
# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2026-01-27

### Added
- Task priority system (Low, Normal, High)
- Task categorization (Design, Development, Marketing, Writing)
- Task dispute resolution system
- Task cancellation with automatic refunds
- Task expiration handling
- Partial payment support
- Payment history tracking
- Task rating system
- Task templates for reusability
- Milestone-based payments
- Task collaboration features
- Enhanced error handling with comprehensive error constants
- Deadline validation (minimum 1 day)
- Real-time task status monitoring
- Modern React UI components
- Comprehensive SDK integration
- Full test coverage

### Enhanced
- Smart contract with advanced features
- Frontend with improved UX/UI
- Documentation with detailed API reference
- Testing suite with multiple test types

### Security
- Enhanced access control
- Input validation improvements
- Error handling enhancements

## [1.0.0] - 2025-12-01

### Added
- Smart contract unit tests for `create-task`, `accept-task`, `submit-work`, and `approve-work`.
- Frontend UI components: Button, Card, Input, Badge, Modal.
- Frontend reusable hooks: `use-task`, `use-wallet`.
- Task listing and details pages.
- Documentation for contracts and frontend.

### Changed
- Refactored `Header` to improved wallet integration.
- Updated `contracts/README.md` with testing guide.
- Updated `frontend/README.md` with component structure.
